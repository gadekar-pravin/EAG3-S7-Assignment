## Assignment

### Build a real RAG application with an aesthetically beautiful UI, deployed on localhost, over the documents in folder "sandbox/court_opinions".

Constraints:
- Design five queries against your corpus. Each must answer correctly with the index and fail without it. 
- At least two must require semantic recall, where the query's words do not appear in the chunks that answer it.
- The grep test on Perception's SYSTEM stays the gate: zero MCP tool names inside. 
- Adding a new MCP tool for a file format your corpus needs is welcome; its docstring is where Decision learns about it.
